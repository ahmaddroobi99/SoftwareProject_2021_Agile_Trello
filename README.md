# PayMe — student e-wallet (Agile team project)

Software engineering course project, Fall 2021. Team of 7; I was Scrum Master.

Despite the repo name, this is **not Trello**. It is **PayMe**, a Java Swing e-wallet for student bill payments (electricity, water, phone), accounts, cards, and an admin view.

The tree has NetBeans Java sources (`src/software/project/`), a SQL dump (`dump1.sql`), UML / sequence / use-case diagrams, UI screenshots, and a demo video (`DemoOfTHeProject_PyME/PayMe.mp4`).

**Stack:** Java, Swing, NetBeans, MySQL
